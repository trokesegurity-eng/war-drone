# war-drone

Simulador de drone subaquático + base arquitetural da plataforma Aquabotia.

## Módulos Aquabotia

- `web-platform-v1/`: protótipo inicial de apresentação.
- `web-platform-v2/`: visão técnica V2 para stakeholders.
- `aquabotia-v2/`: monorepo funcional (backend, embedded, web/mobile scaffold, infra e scripts).
