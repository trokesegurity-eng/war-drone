# war-drone
simulador drone subaquatico

## Dados MVP Brasil (pt-BR)
- Arquivo de configuração inicial: `data/mvp-br-0.1.pt-BR.json`
- Inclui biome pack da Mata Atlântica, catálogo de espécies/ambiente, missões e regras de pontuação.

## Site demonstrativo: HARPA Manta
Foi adicionada uma landing page em português com:
- Simulação em vídeo web (canvas) de um drone-mãe no formato de arraia manta.
- Cardume com peixes pequenos e variados.
- Mini-drones saindo da parte inferior do drone-mãe.
- Seções com curiosidades, arquitetura IA e exemplos de missão.

### Como abrir
Basta abrir `index.html` no navegador.
