# war-drone

Simulador de drone subaquático + arquitetura técnica da Aquabotia Software Factory.

## Módulos principais

- `web-platform-v1/`: protótipo inicial de apresentação.
- `web-platform-v2/`: versão técnica com camadas, stack, fluxo e esquema de dados.
- `aquabotia-v2/`: base funcional V2 (docs + backend FastAPI + embarcado mock + infra + estrutura monorepo).
