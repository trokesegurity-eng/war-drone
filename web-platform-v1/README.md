# AQUABOTIA Plataforma Web V1

Protótipo web estático para apresentar a estrutura da fábrica de softwares do projeto AQUABOTIA com versionamento visual da plataforma.

## Como executar

Basta abrir `index.html` no navegador.

## Recursos

- Estrutura dos 5 núcleos da fábrica.
- Arquitetura operacional ponta a ponta.
- Módulos MVP (1, 2 e 3).
- Roadmap em 12 meses.
- Botão de versionamento (`V1.0.0` -> `V1.0.1`...).
