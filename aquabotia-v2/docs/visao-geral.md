# Visão Geral V2

A V2 organiza o ecossistema Aquabotia em 5 camadas: drone, IA embarcada, API central, plataforma digital e núcleo de dados ambientais.

Objetivos do MVP:
- monitorar qualidade da água;
- identificar espécies aquáticas;
- detectar invasoras;
- gerar alertas e relatórios;
- iniciar base nacional de catalogação.
